# Normalize

The normalize package comes functions to normalize data (like strings).

## `String`

What does this function?

1. Remove all puncts with RegEx `[[:punct:]]`
1. Remove all extra whitespaces with builtin `strings.Fields()`
1. Convert all to lower with builtin `strings.ToLower()`
